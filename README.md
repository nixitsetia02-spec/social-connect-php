# dbsocial

dbsocial is a PHP and MySQL based social networking web application developed as an academic project. It provides essential social media features such as user authentication, profile management, messaging, friend requests, discussion groups, and account recovery.

## Features

- User Registration and Login
- Forgot Password
- User Profile Management
- Edit Profile
- Profile Picture Upload
- Friend Request System
- Private Conversations
- Discussion Topics
- Group Creation and Management
- User Search
- Secure Database Connectivity

## Technologies Used

- PHP

- CSS
- JavaScript

## Requirements

- PHP 8.x
- MySQL
- Apache Server (XAMPP/WAMP)

## Installation

1. Clone the repository.
2. Import the MySQL database.
3. Configure the database connection in `db.php`.
4. Place the project inside the web server directory.
5. Start Apache and MySQL.
6. Open the project in your browser.


## How to Run

### Requirements

- XAMPP/WAMP/LAMP
- PHP 8.x
- MySQL

### Steps

1. Clone or download the repository.
2. Copy the project folder to the `htdocs` directory (XAMPP).
3. Start Apache and MySQL.
4. Import the `database.sql` file into MySQL.
5. Configure the database connection if required.
6. Open the following URL in your browser:

```
http://localhost/dbsocial/login.html
```

> **Entry Point:** The application starts from `login.html`.
